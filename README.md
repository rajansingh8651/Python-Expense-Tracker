# Python Expense Tracker

A Python-based Expense Tracker for managing daily expenses, categories, total spending, and CSV export.

## 🚀 Features

* Add new expenses
* View all expenses
* Calculate total expenses
* Generate category-wise expense reports
* Delete expenses with confirmation
* Export expenses to CSV
* Store expense data in JSON
* Input validation
* Automatic date recording

## 🛠️ Technologies Used

* Python
* JSON
* CSV
* Python `datetime` module

## 📂 Project Structure

```text
├── expense_tracker.py

```

## ▶️ How to Run

1. Install Python 3.x.
2. Clone this repository.
3. Open the project folder.
4. Run:

```bash
python expense_tracker.py
```

## 📋 Menu Options

```text
1. Add Expense
2. View Expenses
3. Total Expenses
4. Category Report
5. Delete Expense
6. Export to CSV
7. Exit
```

## 💾 Data Storage

Expense records are stored in `expenses.json`.

The project can also export expense records to `expenses.csv`.
